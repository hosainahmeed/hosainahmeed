## About

I'm a frontend developer based in Bangladesh, focused on building production-ready web and mobile applications.

My main ecosystem is **React, React Native, TypeScript, and Next.js**. I work across the frontend development lifecycle, including UI implementation, application architecture, state management, API integration, authentication, real-time features, deployment, and app-store releases.

I care about writing code that is **clean, reusable, maintainable, and practical**. I prefer well-structured solutions that can grow with a product without introducing unnecessary complexity.
