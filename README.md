## Engineering Principles

- **Architecture before features** — clear module boundaries and a predictable data flow make every later feature cheaper.
- **Type safety end to end** — TypeScript contracts from the API layer to the UI eliminate whole classes of runtime bugs.
- **Reuse with intent** — shared components and hooks only where the abstraction is proven, never speculatively.
- **Performance as a requirement** — measured render costs, lean bundles, and smooth 60 fps interactions on real devices.
- **Production is the finish line** — code is done when it is deployed, monitored, and maintainable by the next engineer.
